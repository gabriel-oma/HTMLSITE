# Movie Explorer

Aplicação web para descobrir, acompanhar e avaliar filmes — seu cinema, organizado.

## Recursos

- Exploração de filmes, biblioteca pessoal e favoritos.
- Avaliações, estatísticas e diário na nuvem.
- Autenticação e armazenamento com Supabase.

## Tecnologias

HTML, CSS e JavaScript, com Chart.js e Lucide. Catálogo com dados da Studio Ghibli API e integração opcional com TMDB.

Desenvolvido por [Gabriel](https://github.com/gabriel-oma) como parte dos seus projetos web e estudos em programação.
